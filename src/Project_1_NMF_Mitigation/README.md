# Project 1: SOC Alert Fatigue Mitigation Project of NMF

## 📌 Framework Research Focus
This track presents the conceptual methodology blueprint and data-filtering rules mapping for the **Neural Matrix Framework (NMF)** approach. 

### 🔬 Core Theoretical Goals
* **Signal Optimization:** Algorithmic categorization of multi-layered telemetry streams before triage execution.
* **Noise Minimization:** Standardizing threshold rules to screen out repetitive background noise logs.
* **Heuristic Scoring Matrix:** Engineering weight allocations to isolate authentic threats targeting critical organizational nodes.

## 🛠️ Module Architectures
*   `anomaly_detector.py`: Evaluates baseline network activity traffic profiles to isolate anomalies.
*   `feature_eng.py`: Transforms raw telemetry logs into structured mathematical feature arrays.
